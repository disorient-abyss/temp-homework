# 1  BLEU 指标

- 通过对 n-gram 的进行评估，简单来说就是 1-gram 对比上下 2 句子，下面句子中每个单词是否在上面句子出现过，以此计算分数，n-gram 指的是下面句子连续 n 个单词的序列，在上面句子中完整出现来计算分数。

  - 1  文本举例：

  ```python
  generated_text = "This is some generated text."
  # 计算BLEU指标
  reference_texts = ["This is a reference text.", "This is another reference text."]
  c_bleu = coumulative_bleu(reference_texts, generated_text)
  ```

  - 2  运行结果：

  ```zsh
    The Bleu score's [1_gram, 2_gram, 3_gram, 4_gram] are: (0.8571428571428571, 0.6900655593423543, 0.5711187624803536, 0.4920274515385508)
  ```

# 2 ROUGE 指标

- **ROUGE-N（如 ROUGE-1 / ROUGE-2）**：

  - 看**参考句子中的连续 $n$ 个词序列，有多少个在机器生成的句子中被命中了**。命中的比例越高，说明参考内容被覆盖得越全面（ROUGE-1 看词汇覆盖，ROUGE-2 看短语搭配覆盖）。

- **ROUGE-L（最长公共子序列，LCS）**：

  - 不要求单词必须紧挨着连续，而是**看两个句子按先后顺序能匹配上的最长词序列有多长**。只要词语的前后相对顺序一致就能得分，主要用来评估整体句式结构的还原程度。

- **ROUGE-W / ROUGE-S（拓展变体，了解即可）**：

  - **ROUGE-W**：对 ROUGE-L 的加权版，连续命中的词越多权重越高。

  - **ROUGE-S**：跳字二元组（Skip-Bigram），允许两个词之间隔着其他词来匹配对子。

  - 1  文本举例：

  ```python
  # ⽣成⽂本
  generated_text = "This is some generated text."
  
  # 计算 ROUGE 指标
  reference_texts = ["This is a reference text.", "This is another generated reference text."]
  rouge = Rouge()
  scores = rouge.get_scores(generated_text, reference_texts[1])
  ```

  - 2  运行结果：

  ```zsh
  ROUGE-1 precision: 0.8
  ROUGE-1 recall: 0.6666666666666666
  ROUGE-1 F1 score: 0.7272727223140496
  ```

> [!Summary] **ROUGE 指标**
>
> ROUGE 就是**以参考句子为基准，算 n-gram 的覆盖率（召回率）以及词序一致的最长公共子序列长度**。

# 3  PPL 困惑度指标

**困惑度（Perplexity, PPL）的核心思想是：看模型在面对真实句子时，对“预测下一个词”有多迷茫。数值越低，说明模型越自信、句子越符合自然语言逻辑。**

按同样的逻辑，精炼总结如下：

- **核心机制（预测真实词的概率乘积）**：
  给定前文，让模型预测下一个实际出现的词。如果模型给每个真实词分配的概率都很高，整体困惑度就很低；反之，模型越觉得真实词“出乎意料”，困惑度就越高。

- **直观理解（单选题的分支因子）**：
  如果一个模型的 PPL 是 10，相当于它在预测下一个词时，平均在 **10 个等概率的可能选项里做选择题**。候选分叉越少，说明越聚焦。

- **数学本质（交叉熵损失的指数变换）**：
  $\text{PPL} = e^{\text{Loss}}$（其中 Loss 是模型在测试集上的平均交叉熵损失）。训练模型时降低 Cross-Entropy Loss，本质上就是在直接压低困惑度。

  - 1  文本举例：

  ```python
  # 定义语料库
  sentences = [
      ['He', 'has', 'a', 'book'],
      ['She', 'has', 'a', 'cat'],
      ['I', 'have', 'a', 'pen'],
  ]
  
  unigram = {
      'I': 1/11,
      'have': 1/11,
      'a': 3/11,
      'pen': 1/11,
      'He': 1/11,
      'has': 2/11,
      'cat': 1/11,
      'book': 1/11,
      'She': 1/11,
  }
  ```

  - 2  运行结果：

  ```zsh
  困惑度为: 7.446303021787187
  ```

> [!Summary] **PPL指标**
>
> 困惑度就是**交叉熵损失的指数次方，用来衡量模型面对真实文本时平均有多“意外”，数值越小代表模型预测得越准。**
