# 更改后的结论

- **前向传播与初始损失**
  
  $q = x + y = -2 + 5 = 3$
  
  $f = q \cdot z = 3 \cdot (-4) = -12$
  
  $L_\text{old} = \frac{1}{2}(f - f_\text{target})^2 = \frac{1}{2}(-12 - (-11))^2 = 0.5$

- **反向传播求各参数梯度**
  
  $\frac{\partial L}{\partial f} = f - f_\text{target} = -12 - (-11) = -1$
  
  $\frac{\partial L}{\partial z} = \frac{\partial L}{\partial f} \cdot q = (-1) \times 3 = -3$
  
  $\frac{\partial L}{\partial q} = \frac{\partial L}{\partial f} \cdot z = (-1) \times (-4) = 4$
  
  $\frac{\partial L}{\partial x} = \frac{\partial L}{\partial q} \cdot \frac{\partial q}{\partial x} = 4 \times 1 = 4$
  
  $\frac{\partial L}{\partial y} = \frac{\partial L}{\partial q} \cdot \frac{\partial q}{\partial y} = 4 \times 1 = 4$

**参数更新（$\eta = 0.1$）**

应用标准梯度下降公式 $w_\text{new} = w_\text{old} - \eta \cdot \frac{\partial L}{\partial w}$：

$z_\text{new} = -4 - 0.1 \times (-3) = -4 + 0.3 = -3.7$

$x_\text{new} = -2 - 0.1 \times 4 = -2 - 0.4 = -2.4$

$y_\text{new} = 5 - 0.1 \times 4 = 5 - 0.4 = 4.6$

**重新前向传播验证**

- **计算新输出**
  
  $q_\text{new} = x_\text{new} + y_\text{new} = -2.4 + 4.6 = 2.2$
  
  $f_\text{new} = q_\text{new} \cdot z_\text{new} = 2.2 \times (-3.7) = -8.14$

- **计算更新后的损失**
  
  $L_\text{new} = \frac{1}{2}(f_\text{new} - f_\text{target})^2 = \frac{1}{2}(-8.14 - (-11))^2 = \frac{1}{2}(2.86)^2 = 4.0898$

**结果现象说明**

当学习率设为 $\eta = 0.1$ 时，$L_\text{new} = 4.0898 > L_\text{old} = 0.5$。

此时输出从 $-12$ 直接跳到了 $-8.14$，与目标值 $-11$ 的距离从原本的 $1.0$ 扩大到了 $2.86$。因为非线性函数（乘法门）的局部斜率仅在极小邻域内近似成立，过大的学习率导致更新步长过大，直接跨过最优解并发生了典型的**超调（Overshooting）**。这正是深度学习训练中学习率过大导致损失不降反升、震荡发散的标准体现。

# 更改前的错误标注

对比两者在 $\eta = 0.1$ 下的表现，会发现荒谬之处主要集中在以下三个层面：

**步长被暗中缩小了 16 倍**

正统梯度下降中，$x$ 的梯度是 $4$，在 $\eta=0.1$ 时单步步长是：

$\Delta x = 0.1 \times 4 = 0.4$

因为非线性乘法门的存在，步长 $0.4$ 太大直接导致输出超调（直接冲到了 $-8.14$）。

而课件由于把偏导数移到了分母上（写成 $\partial x = -\frac{1}{4}$），计算出的步长变成了：

$\Delta x = 0.1 \times \frac{1}{4} = 0.025$

课件的步长比正统梯度下降**小了整整 16 倍**。作者误打误撞通过“取倒数”把步长压得极小，才碰巧没有在非线性区域冲过头，造出了一个“看似逐渐收敛”的假象。

**彻底反向的动力学行为**

课件这套更新规则如果真写进神经网络底层，模型会彻底瘫痪：

- **遇到平坦区域直接崩溃：** 当参数导数接近 $0$ 时（例如特征不重要或处于极值点），正统梯度下降会平缓停止更新；而课件因为除以导数，更新量会变成 $\frac{1}{0} \to \infty$，单步直接溢出导致参数变成 `NaN`。

- **遇到陡峭区域形同冻结：** 当梯度极大（如梯度为 $100$）需要快速逃离鞍点时，课件的更新量反而变成 $\frac{1}{100} = 0.01$，参数完全学不动。

**一维试凑强套多元微积分**

课件作者把多元微积分当成了一元一次方程来解：

- 课件认为：要让 $f$ 变化 $1$，所以让 $z$ 变 $\frac{1}{3}$，让 $x$ 变 $-\frac{1}{4}$，让 $y$ 变 $-\frac{1}{4}$。

- 真实情况是：这三个变量同时变化时，输出的改变量是它们的线性累加：
  
  $\Delta f \approx 3 \times \frac{1}{3} + (-4) \times \left(-\frac{1}{4}\right) + (-4) \times \left(-\frac{1}{4}\right) = 1 + 1 + 1 = 3$
  
  这一套计算在微积分上属于完全不成立的独立假设，无法推广到任何拥有两层以上或者矩阵相乘的神经网络中。
